OpenJKDF2 for iOS (unofficial)

Star Wars Jedi Knight: Dark Forces II and Mysteries of the Sith on iPhone and iPad: an unofficial fan port of OpenJKDF2, with touch controls, game controllers, a keyboard and multiplayer.

Install

Easiest, in SideStore or AltStore (Classic): add the source, then install OpenJKDF2 (Jedi Knight), OpenMoTS (Mysteries of the Sith) or both from it.

Add to SideStore Add to AltStore

If a button does nothing, add the source by hand (in the app's Sources, tap +) with this address:
https://raw.githubusercontent.com/sithewok13-dev/OpenJKDF2-iOS/claude/openjkdf2-ios-build-2gcr9s/packaging/ios/altstore-source.json

Latest release Setup guide

What you need

  • Your own copy of the game, from GOG or Steam. No game files are included: you copy yours into the app with the Files app.
  • An iPhone or iPad with iOS 18 or newer, and a sideloading app such as SideStore, AltStore (Classic) or Sideloadly.
  • A little patience: it's a beta. Expect bugs, and back up your saves.
